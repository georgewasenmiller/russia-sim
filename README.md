# Россия 2000: политико-экономический симулятор

Пошаговый политико-экономический симулятор России, стартующий в 2000 году,
в стилистике HOI4 / Millennium Dawn — без военного слоя, фокус на
макроэкономике и внутренней политике. Ключевая механика: колеблющаяся
мировая цена на нефть/газ напрямую двигает доходы бюджета.

## Стек

React + TypeScript + Vite, Tailwind CSS, Recharts, lucide-react.
Сохранение — `localStorage` браузера, без бэкенда.

## Разработка

```bash
npm install
npm run dev      # дев-сервер
npm test         # unit-тесты (Vitest) на игровой движок
npm run build    # прод-сборка
```

## Структура

- `src/engine/` — чистая игровая логика (типы, формулы, отрасли, реформы,
  события, оркестрация хода, сохранение). Не зависит от React.
- `src/state/GameContext.tsx` — React-обвязка над движком (reducer + actions).
- `src/components/` — UI: дашборд показателей, графики истории, ползунки
  политики, панели отраслей/реформ, модалка событий.
